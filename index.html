Privacy Policy

What Clips GTA6 is. Clips GTA6 is a private, single-user desktop tool run by the owner of the YouTube channel grand theft xtreme. It edits short clips from videos of creators who have authorized clipping, and uploads them, after the owner manually approves each one, to the owner's own YouTube channel. It has no other users and no public sign-up.

Use of YouTube API Services. Clips GTA6 uses YouTube API Services. By using it, the operator agrees to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

Data accessed. Through Google OAuth 2.0 the tool requests only:

  • youtube.upload — to upload videos and thumbnails to the owner's channel;
  • youtube.readonly — to read the owner's own channel name and basic information, to confirm that uploads go to the right channel.

The tool does not access, collect or store data about any other YouTube user, viewers, comments or subscribers.

Storage. The OAuth token is stored only on the owner's local computer. The tool keeps a local database with the status of each clip (video ID, timestamps, title, upload status). Nothing is stored on any server operated by the tool.

Sharing. Google user data is never sold or shared with third parties. Video transcripts of public videos are sent to the Anthropic Claude API only to select highlight timestamps and write titles; no Google account data is sent.

Retention and deletion. Local files and data can be deleted at any time by the owner. Access can be revoked at any time at myaccount.google.com/permissions; after revocation the tool can no longer upload. Stored API data is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.

Cookies. The tool does not use cookies or similar tracking technologies.

Terms of Service

  1. Clips GTA6 is a private tool for the exclusive use of its operator. It is not offered to the public.
  2. Use of the tool is subject to the YouTube Terms of Service and the YouTube API Services Terms of Service.
  3. Only content from creators who have authorized clipping is processed. Every clip credits the original creator and links to the original video.
  4. No content is published without the operator's explicit approval of each clip.
  5. The tool is provided "as is", without warranties.
